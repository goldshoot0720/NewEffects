# 逆境無頼カイジ（OP/ED 共用角色素材）

PV 55「未来は僕等の手の中」與 PV 56「負け犬たちのレクイエム」共用這組八人立繪。

## 檔案

| 檔案 | 內容 |
| --- | --- |
| `lineup.jpg` | 使用者提供的白底八人立繪（1920×720） |
| `../cast/kaiji-0..7.png` | 切出的八張透明精靈 |
| `../kaiji-group.png` | 1920×1080 群像主視覺 |

## 角色

索引 0–7：船井、遠藤勇次、古畑、北見、伊藤開司（主唱）、石田、大槻、兵藤和尊。

## 切圖

`tools/cutout-kaiji.py`：

1. 白底從邊界連通移除，門檻用亮度 > 200（JPEG 抗鋸齒的白會一路掉到 200 左右）。
2. 相鄰角色手臂之間的白色會被包住，先清「高而窄的淺色封閉區」，再清「貼著裁切左右邊緣的淺色區」。
3. 角色腳踩在畫面底邊，腳與腳之間的白色清不到，底部 12% 直接把淺色清掉。
4. 八人靠得很近（只有最左邊有完全透明列），所以用固定的列邊界切開。

重建：

```bash
python3 tools/cutout-kaiji.py
```
