# FX戦士くるみちゃん：福賀くるみ(CV.鈴木愛奈)

TV 動畫《FX戦士くるみちゃん》片頭曲。PV 編號 53，長度 203.75 秒。

## 素材

- 音源：使用者提供的 `FX戦士くるみちゃん.mp3`（5,101,721 bytes）。
- 日文原文：歌ネット（uta-net.com/song/400331）公開歌詞，未改寫；依實際唱出的樂句拆成 60 句，重複的「押せ！」保留四段。
- 繁中翻譯：本專案翻譯，逐句對應，寫在 `lyrics-zh.txt`。
- 人物：使用者提供的四張官方透明立繪（`kurumi.png`、`mochiko.png`、`mebuki.png`、`yasuko.png`），由 `tools/cutout-fx.py` 裁切並拼成群像 `assets/ref/fx-group.png`。

## 字幕時間軸

這首節奏快、口白與喊唱交錯，`whisper-cli large-v3-turbo` 的辨識文字不可用，分段時間也不穩（同一句在不同視窗會差到 2 秒以上），因此不再拿 ASR 當錨點：起唱點逐一對過前景音訊的音節峰，句尾改用「最後一段還在唱的地方」量測，`timings-ja.json` 每句都標 `final: true`，SRT 不再提前或延長。間奏 59–78 秒與 89–91 秒不掛字幕。

```bash
python3 tools/build-srt.py assets/ref/fx/timings-ja.json assets/ref/fx/lyrics-zh.txt FX戦士くるみちゃん.srt
```

## 逐字填色

`fill-ja.json` 記每句的起唱／唱完，以及每個字（空白與標點不算）唱到的時間，兩個播放器共用。

- 產生方式：`python3 tools/measure-fx.py`。先用 librosa 的 REPET-SIM 把重複的伴奏壓掉，留前景（主唱），在 250–5000 Hz 的能量包絡上找音節峰；峰比字多就把峰分組取平均，峰比字少就一個峰配多字、段內依字重切。句尾量到的最後一段歌聲若離字幕結尾超過 0.8 秒，視為量錯、保留原值。
- 「円」是拉長的長音（到 1:51.55 才換氣），顫音會被當成新字，這一句照實際唱法切成一段。
- 填色的字數規則跟 `LyricText.clean` 一致：空白、標點與符號（`\p{P}\p{S}`）都沒有時間。`pv.js` 的 `attachFill` 原本把標點、`・`、`!!!` 都算成字，逐字時間對不上就整句丟掉（舊資料只有 3 句，且時間還停在換行前的位置），現在改為逐字跳過 `\p{P}\p{S}`，60 句都套得上；同一支程式也把〈Forever＆ever〉的 43 句從 32 句補到全數套用。
- 檢查：`node tools/test-fx-fill.mjs` 會用跟 `pv.js` 相同的斷詞跑一次，確認 60 句的字數、順序與時間範圍都對得上。

## 卡司

四位：福賀くるみ（主唱，索引 0）、小金萌智子、山師芽吹、高根やす子。舞台分鏡對四人卡司另有一組站位（兩位配角站前排兩側、第三位站主唱左後方；後排正中央會被主唱整個擋住），見 `pv.js` 的 `shotStage`。`series` 設為主唱名「福賀くるみ」，片頭貼紙與左上角 HUD 才不會和歌名重複。
