# 風の中は走るっきゃないっ！ 六人（生徒会にも穴はある！）

「風の中は走るっきゃないっ！」是三月のパンタシア演唱的 TV 動畫《生徒会にも穴はある！》片頭曲（2026 年 10 月播出，單曲 11 月 25 日發行）。這首歌原本沿用 ED 曲「ぴ」的 anaru 群組（站姿看板圖），本組改用官方網站公開的 OP 版角色立繪：六人各自單獨去背、正在跑步的造型，正好對應歌名。

## 重建

執行 `node tools/build-kaze.mjs`：裁去每張立繪外的透明空白、補 8 像素透明邊距並限制在 900 像素高，寫入 `cast/kaze-0.png`～`kaze-5.png` 與 `cast.json` 的 kaze 群組，再拼出 `group.png`。

六張都是「跑起來」的姿勢畫，伸出的手臂和跨開的腿一旦被拆成手腳層就會從肩膀或大腿撕開，因此全部標記 `intact: true`，讓 `dance-rig.js` 整張畫只做跳躍、微跳與傾斜。群像圖用 3 × 2 排列並以等高縮放（跑步姿勢的張開幅度差很多，壽子的長髮最寬，用等寬會把她壓得比其他人大一截）。
