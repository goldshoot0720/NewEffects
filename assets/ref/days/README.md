# DAYS!（Aooo）

- 歌名、演唱者 Aooo 與完整日文歌詞由使用者提供。這首是 TV 動畫《グロウアップショウ ～ひまわりのサーカス団～》的 ED 主題曲（作詞・作曲：ツミキ、編曲：Aooo）。
- PV 編號 `52`，第二版播放器 ID `aooo-days`。兩版播放器與人物 PV 沿用同作的 `growup` 十人，主唱預設鶴巻瑞佳；歌詞 PV 使用 `days` 主題（放學後的晴空到向日葵黃）。
- 音源 231.00 秒，MP3 與同步 SRT 隨 repo 部署，部署版可直接播放。
- `lyrics-ja.txt` 保存使用者提供的原文，長句依實際唱出的樂句拆成 57 句（例如「教科書に書いていない／いつものしあわせは」、「そんな当たり前にあるしあわせ／一生の宝物！」），文字不增不改；`translations-zh.json` 逐句對應繁中翻譯，重唱句共用同一組譯文。
- `timings-ja.json` 依這份音源對時：`assets/ref/days/asr.py` 先以 `ffmpeg` 轉 16 kHz 單聲道，交給 `faster-whisper medium` 取詞級時間戳（`asr-ja.json`），再以詞的起唱點決定每句開始；句尾收到下一句開始前 0.1 秒，遇到間奏則在最後一個字唱完後收掉，不拖進空檔。第一句與「見つけられたらいっそ」等長句因此各自拆成兩段。
- 歌詞裡的兩行 `(Oh, oh, oh-oh, oh-oh)` 是和聲呼喊，落在「行ける気がするのさ」之後（161.90–164.30）與「どんな未来でも変わらないひかりを」之後（210.30–212.60）的空檔；ASR 不會辨識這種非語詞段落，位置依歌詞順序與實際空檔決定。這兩行沒有翻譯，`translations-zh.json` 留空字串，字幕只輸出一行，避免同一句在原字與翻譯各顯示一次。
- 執行 `node tools/build-days-subtitles.mjs` 可重建 SRT，並檢查 57 行原文完整、時間不重疊且都在音源長度內。
