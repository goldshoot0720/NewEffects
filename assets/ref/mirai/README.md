## 字幕時間軸

整首跑的 ASR 只抓到 30 秒之後，前 30 秒是空的；改用 0–36 秒的局部視窗重跑後，人聲其實從 11.98 秒就進來。段落：

- 0–11.98 前奏
- 11.98–33.84 第一段（最後一句重唱一次）
- 39.26–60.98 第二段（最後一句重唱一次）
- 60.98–93.30 吉他間奏，沒有人聲
- 93.30–95.48「未来は僕等の手の中!!」
- 101.04–123.40 最後一段（最後一句重唱一次）
- 123.40–149.00 outro


## 角色素材

九個人互相重疊，去背後是**單一連通域**，無法自動分離成單人立繪。因此 `tools/cutout-mirai.py` 把整組當一個 `intact` 精靈：

1. 近白從邊界連通才移除；腳下的淺灰陰影（218–222）另外按行亮度清掉。
2. 兩腿之間被包住的純白空隙連不到邊界，用「純白且面積 > 400 的內部連通域」移除。
3. 主視覺先鋪一層放大模糊的群像當底，再把清晰的群像置中，避免左右空白。

因為卡司只有一人，`pv.js` 的分鏡選擇加了 `canWin` 判斷：卡司不足三人時不排「三窗」鏡頭，否則同一張圖會重複三次。

重建：

```bash
python3 tools/cutout-mirai.py
```
