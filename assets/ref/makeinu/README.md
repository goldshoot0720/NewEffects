# 負け犬たちのレクイエム（ろくでなしBLUES）

TV 動畫《ろくでなしBLUES》插入曲。PV 編號 56，長度 322.20 秒。

## 檔案

| 檔案 | 內容 |
| --- | --- |
| `asr-ja.json` | `tools/asr.py`（faster-whisper large-v3-turbo）的逐句與逐詞時間 |
| `../../負け犬たちのレクイエム.srt` | 33 句日中雙語字幕，由 `tools/build-makeinu-subtitles.mjs` 產生 |

角色素材沿用 `assets/ref/mirai/`（同一部作品的九人合圖），沒有另外切圖。

## 時間軸

歌詞唱兩輪：

- 第一輪 28.12–152.94（28 秒前是前奏，ASR 把開頭的「やまない」聽成「ヤバナイ」）
- 第二輪 198.96–292.68
- 197.56–198.96 的「作詞・作曲 初音ミク」是 ASR 幻聽，不採計
- 294.62–295.98 的「アーメン」有收進字幕

ASR 會把兩三句併成一段，這裡用詞級時間切回每一句；切點就是該句第一個詞的開始時間。

重建：

```bash
node tools/build-makeinu-subtitles.mjs
```
