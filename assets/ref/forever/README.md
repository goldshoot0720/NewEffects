# Forever＆ever

彩音的〈Forever＆ever〉，恋愛アドベンチャー《メモリーズオフ 双想 Break out of my shell》片頭曲。作詞彩音，作曲・編曲磯江俊道。使用者提供的音訊約 256.92 秒，檔案內的 YouTube ID 是 `31bvn6GUtaI`。

- `lyrics-ja.txt` 是使用者提供的 43 行日文，保留全形 `＆`、`Story－旅路－` 與 `Storyー旅路ー` 的兩種寫法、`扉ードアー`，以及「“約束”」「“誓い”」的空格。
- `lyrics-zh.txt` 是對應的 43 行繁中。
- `timings-ja.json` 是對到音訊後的 43 段時間軸，與 `lyrics-ja.txt` 逐行對應。片尾在第二次「世界まで変えよう」之後是間奏，接著只再唱「Storyー旅路ー」與「あの潮風に乗って」。
- 封面是使用者提供的單曲ジャケット，存成 `cover.png`。六位女主角的全身立繪來自 `standing.jpg`，去背後存成 `../cast/forever-0.png`～`forever-5.png`：フェルスター・マリー・暁空、田中結、北方和音、洲宮紗絵、天羽ねね、中森雪加。原圖手勢和抬腳都留著，所以 `armScale` 是 0.08、`legScale` 是 0.15。預設主唱是洲宮紗絵。

時間軸以整首 PCM 的詞級時間戳逐句對過起唱：每句的開始取這句第一個字量到的詞首（再提前 0.05 秒），結束取最後一個字量到的詞尾加 0.45 秒，若下一句已經起唱就收在下一句出現前。`timings-ja.json` 存的就是這組最終時間（`final: true`），`tools/build-srt.py` 看到這個欄位就不再套用「提前 0.18 秒、句尾收到下一句前 0.05 秒」的舊規則，所以根目錄的 `Forever＆ever.srt` 與它逐句相同。片尾在第二次「世界まで変えよう」之後仍是間奏，只再唱「Storyー旅路ー」與「あの潮風に乗って」。

## 逐字填色

一句可能有兩段（「宝物みたいな時間　未来動かす小さな願い」中間隔了兩秒半），填色若照字幕視窗線性跑，間奏時就會把後半句提前點亮；句尾多留的時間也會讓最後幾個字慢半拍。`pv.js` 的 `FOREVER_SYLLABLES` 因此記下每個字唱完的秒數（來源同樣是這份詞級對齊），填色跟著字走，句中停頓就停在那裡。每串數字的個數要與 `lyric-text.js` 的 `clean()`、`pv.js` 的 `tokenize()` 切出來的字母數一致；`node tools/test-lyric-text.mjs` 會一併檢查這件事。
