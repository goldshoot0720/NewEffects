# マトリョーシカ（NICO Touches the Walls）

PV 編號 59，長度 300.35 秒。

## 檔案

| 檔案 | 內容 |
| --- | --- |
| `lineup.jpg` | 使用者提供的九人立繪（黑底、附名牌，1822×863） |
| `asr-ja.json` | `tools/asr.py`（faster-whisper large-v3-turbo）的逐句時間 |
| `../../マトリョーシカ.srt` | 33 句日中雙語字幕，由 `tools/build-matryoshka-subtitles.mjs` 產生 |

## 字幕時間軸

整首 ASR **漏掉開頭**（兩次都從 30.00 秒才開始），22.10 秒的第一句是另外用 16–36 秒的局部視窗補回來的。段落：

- 0–22.10 前奏
- 22.10–133.44 第一、二段
- 133.44–156.72 間奏
- 156.72–217.12 第三段
- 217.12–234.12 間奏
- 234.12–245.06 收尾（含最後一句「マトリョーシカ」）
- 245.06–300.35 outro

ASR 把「マトリョーシカ」聽成「惑う力」、「引っ剥がして」聽成「引っ張らして」、「ありったけ」聽成「ありった元気」，字幕一律以使用者提供的歌詞為準。

## 角色切圖

`tools/cutout-matryoshka.py` 從黑底立繪切出九人：

1. 先裁掉底部名牌（y ≥ 712）。
2. 黑底用「從邊界連通的暗色（亮度 < 26）」判定——衣服的黑色因為被輪廓包住，不會被吃掉。
3. 九人彼此相連（只有 5 段完全透明列），因此用固定的列邊界切開，而不是連通域。
4. 輸出 `assets/ref/cast/matryoshka-0..8.png`，寫入 `cast.json` 的 `matryoshka` 群組，並拼成群像 `assets/ref/matryoshka-group.png`。

已知小瑕疵：少數角色邊緣會夾到隔壁的一小塊（例如鞋尖），不影響整體。

重建：

```bash
python3 tools/cutout-matryoshka.py
```
